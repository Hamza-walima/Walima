# Muskan & Hamza — Walima RSVP

A newspaper-style, mobile-friendly Walima invitation with a WhatsApp RSVP form.

## Live site

Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

The expected public URL is:

https://hamza-walima.github.io/Walima/

## RSVP

The RSVP form opens WhatsApp with the guest's response pre-filled for the configured receiving number. The guest then taps **Send** in WhatsApp.
